# Renan Mendes | Advocacia Especializada

Site institucional em HTML, CSS e JavaScript puros, sem build. Pronto para GitHub Pages.

## Seções (na ordem do briefing)
1. Header e Hero
2. Apresentação
3. Áreas de atuação
4. Sobre Renan Mendes
5. Atuação na prática
6. Atuação nacional
7. Chamada final (WhatsApp)
8. Rodapé
+ Página de Política de Privacidade

## Estrutura
```
index.html                    página principal
politica-de-privacidade.html  política de privacidade (LGPD)
assets/css/tokens.css         design system: cores, tipografia, espaçamentos
assets/css/base.css           reset, tipografia global e peças reutilizáveis
assets/css/<seção>.css        um arquivo por seção
assets/js/main.js             abre/fecha o menu no celular
assets/img/                   fotos otimizadas (WebP + JPG) e símbolo da marca em SVG
```

## Como ver
Abra o `index.html` no navegador.

## Como publicar no GitHub Pages
1. Crie um repositório e envie todos os arquivos desta pasta.
2. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
3. O site fica no ar em alguns minutos no endereço que o GitHub mostrar.

## Pendências antes de publicar
Procure por `PROVISÓRIO` e `TEXTO-MODELO` no código: são os textos que precisam
da aprovação do Renan (apresentação, áreas, sobre e política de privacidade).
