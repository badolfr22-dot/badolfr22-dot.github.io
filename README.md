## Sobre

Sou desenvolvedor em formação, com base em Python e desenvolvimento web. Faço sites para pequenos negócios e profissionais liberais, como escritórios, pousadas, restaurantes e comércios locais, e uso inteligência artificial para facilitar o dia a dia de quem não tem tempo para tecnologia.

## Sobre este projeto

- Página única feita com **HTML e CSS puros**, sem frameworks
- **Responsiva**: funciona bem no celular e no computador
- **Tema claro e escuro** automático, seguindo a configuração do aparelho
- Cuidados de **acessibilidade**: foco visível no teclado, contraste adequado e respeito à preferência por menos animação

## Como rodar localmente

Não precisa instalar nada. Basta baixar o repositório e abrir o arquivo `index.html` no navegador.
